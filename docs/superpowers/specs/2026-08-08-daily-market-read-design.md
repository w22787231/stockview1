# 每日市場判讀分頁：設計規格

## 目的

在「總體市場」新增與「總覽／個股二階導／Williams %R」並列的「每日判讀」分頁。它將既有資料收斂成每天可快速核對的市場結論，不改變既有總覽與資料匯出流程。

## 範圍

第一版僅使用已部署的四個資料檔：`macro.json`、`sentiment.json`、`macro_score.json`、`us_theme_flow.json`。不新增 BEI、MOVE、30 年殖利率、RSP/IWM/KRE 等資料源；未取得的資料不以推測值替代。

## 版面與資訊架構

分頁依序呈現：

1. **市場主題列**：市場主題、確信度、行動燈號與資料更新時間。
2. **白話結論**：以一段話說明當日主導因子與股市含意。
3. **今日主角與推翻訊號**：列出最強／最弱產業、關鍵宏觀因子，以及最多兩個可驗證的反向條件。
4. **六項市場檢查表**：實質利率、利率曲線、美元與黃金、信用與流動性、市場情緒、股票內部與資金輪動。每列包含現況、方向／訊號、判讀與狀態燈號。
5. **口徑與限制**：標明資料頻率不一致，並說明此頁是盤後日線判讀，非即時交易訊號。

## 資料與判讀規則

### 六項檢查表

| 模組 | 優先資料 | 判讀方向 |
| --- | --- | --- |
| 實質利率 | 10Y TIPS、日變動 | 上升偏緊縮；下降偏寬鬆 |
| 利率曲線 | 2s10s、分數／歷史位置 | 偏平且走低為壓力；改善為中性至支持 |
| 美元與黃金 | DXY、黃金日變動 | 美元走強且黃金走強視為避險確認；否則中性 |
| 信用與流動性 | HYG、FSI、NFCI、PI、SOFR-IORB | 信用走弱或壓力升高為風險；其餘中性／支持 |
| 市場情緒 | VIX、VXN、SKEW、Fear & Greed、0DTE PCR | 波動／尾部風險升高為風險；極端訊號僅提醒、不獨立反向交易 |
| 股票內部與輪動 | 20/50MA 廣度、新高新低、主題資金流 | 廣度健康且存在中長線強勢組別為輪動；廣度惡化與資金同步流出為撤退 |

### 市場主題

依六項模組的多空狀態分類：

- **風險偏好擴散**：股票內部偏多、信用／流動性非風險，且至少一個利率或情緒模組支持。
- **板塊輪動**：股票內部尚可，但領漲／領跌組別分化，或利率／情緒訊號未能全數支持。
- **防禦升溫**：信用／流動性或情緒偏風險，且美元與黃金出現避險確認。
- **風險撤退**：信用／流動性、情緒、股票內部三者中至少兩者偏風險。
- **訊號分歧**：以上條件均未滿足，或關鍵資料缺漏。

### 確信度與推翻訊號

確信度顯示「支持目前市場主題的模組數／有效模組數」，並映射為低、中、高。推翻訊號只引用現有資料中的可驗證門檻，例如：50MA 廣度跌破 50%、HYG 續跌且 FSI 上升、VIX 升破既有警戒值、資金流由淨流入轉為同步流出。若缺資料，不產生該條件。

## 元件邊界

- `buildDailyRead(data)`：純函式，接收四份資料並輸出主題、信心、模組列、主角與推翻訊號；不讀取 DOM、不發請求。
- `renderDailyRead(viewModel)`：只負責 HTML 呈現與狀態色彩。
- `loadDailyRead()`：平行載入所需 JSON；任一檔案缺失時保留可用資料，並在頁面顯示資料缺漏。
- 分頁切換延用 `MACRO_TAB`／`renderMacroTabBody()` 現有模式。

## 錯誤處理與資料新鮮度

- 每個資料來源都顯示其最新時間；頁面使用最舊的關鍵資料時間作為保守提醒。
- 載入失敗不讓整頁失效：相對模組顯示「資料待補」，不列入確信度分母。
- 不把週／月頻率指標解讀為盤中變化；頁尾固定揭露此限制。

## 測試

新增 Node 測試驗證純判讀函式：

1. 信用、情緒、股票內部同時風險時分類為「風險撤退」。
2. 內部健康但板塊分化時分類為「板塊輪動」。
3. 關鍵資料缺漏時不虛構訊號，並降低有效模組數。
4. 產出的確信度與推翻條件都可由輸入資料追溯。
5. 前端煙霧測試確認新分頁標籤與主要區塊存在。

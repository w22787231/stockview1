# 每日市場判讀：量化判讀表設計

## 目標

將「總體市場 → 每日判讀」的詳細表格調整為參考圖的判讀格式：每個變數各自呈現現值、短中期變化、歷史水平與獨立結論。系統不產生總分、不提供買賣建議。

## 版面

詳細表格欄位固定為：

`變數｜現值・資料日｜今日｜水平｜1D｜5D｜20D｜判讀結論｜註記`

- **水平**：以同一變數的可用歷史資料計算百分位，顯示「高 98%」「中 65%」或「低 18%」。
- **判讀結論**：由該列自己的量化規則產生，例如「↑ 加速」「↓ 避險」「橫盤」「新高」「背離」。
- **註記**：一行白話說明量化結論的原因與含義。
- 資料不足、頻率不相容或來源失敗時，該欄顯示「資料待補」，不產生結論。

頁首保留並改由各列結論彙整：市場主題、白話解讀、確信度、推翻訊號、今日主角。下方保留利率結構、波動／信用壓力、股票內部三張圖。

## 指標與判讀口徑

| 群組 | 指標 | 主要量化口徑 | 結論方向 |
| --- | --- | --- | --- |
| 利率／通膨 | 2Y、10Y、30Y、10Y TIPS、10Y BEI | 5D／20D bp 變化與歷史百分位 | TIPS 上升＝估值壓力；BEI 上升＝通膨升溫；名目利率快速上升＝利率壓力 |
| 信用／波動 | HY OAS、IG OAS、MOVE、VIX、VIX3M、VIX9D | 利差 bp 變化；指數相對 20D 均值；短端／中端比值 | 利差擴大、MOVE 或 VIX 升高、VIX9D/VIX 大於 1＝避險升溫 |
| 股票內部 | RSP/SPY、IWM/SPY、KRE/SPY | 5D／20D 相對 SPY 報酬 | 多數同步為負＝內部轉弱；僅個別分化＝板塊輪動 |

每列內部使用 `-2` 至 `+2` 的規則分數判定方向，但畫面只顯示結論標籤與理由；分數不跨列相加、不顯示市場總分。

## 頁首彙整規則

- **市場主題**：依現有六項模組為主，並由已具結論的詳細列補強文字，不改為總分。
- **確信度**：顯示支持目前主題的有效旁證數／可用旁證數，以及連續同向的交易日數。
- **推翻訊號**：列出與目前主題相反、且可由同一張表驗證的門檻。
- **今日主角**：選取絕對量化分數最高的三列，顯示其變動與結論。

## 資料與可靠性

- `daily_checklist.json` 新增每列的歷史百分位、內部判斷分數、結論標籤及註記。
- exporter 使用交易日序列；缺值只會跳過無效觀測值，絕不以零補值。
- 前端僅渲染 exporter 明確輸出的可用資料；若新版 JSON 尚未部署，維持既有六項摘要並顯示詳細表待補。

## 驗證

- Python 單元測試：百分位、方向門檻、缺資料、bp 與相對報酬口徑。
- 前端測試：完整欄位、結論標籤、資料待補、無總分文字與三張圖容器。
- 部署後驗證：`daily_checklist.json` 必須可存取且為 JSON。

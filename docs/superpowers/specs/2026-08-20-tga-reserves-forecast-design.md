# TGA 與銀行準備金自動預估

## 目標

在「總體市場」新增流動性預估區塊，顯示 TGA 與聯準會存款機構準備金的最新實際值，以及 1 個月與 3 個月的模型預估。所有預估都必須清楚標示為模型情境，不能呈現為財政部或聯準會的官方預測。

## 資料與更新

1. 歷史 TGA：FRED `WTREGEN`，日頻率、百萬美元。
2. 歷史準備金：FRED `WRESBAL`，週頻率、百萬美元。
3. 準備金推導輔助：FRED `WALCL`（Fed 資產）與 `RRPONTSYD`（隔夜逆回購）。
4. 每次既有資料發布工作流執行時，重新抓取資料、重算預估並輸出 `liquidity_forecast.json`；前端只讀 JSON，不在瀏覽器做預測。
5. 任一必要來源缺失、資料日期落後超過對應頻率兩期，或樣本不足時，保留實際資料但不輸出預估線，並標示資料待補。

## 預估方法

### TGA

以最近三個完整年度同一日曆窗口的日變動做預測樣本。基準情境使用中位數日變動；寬鬆與緊縮情境分別使用第 25 與第 75 百分位。預測每日累積，產生 21 個交易日（約 1 個月）與 63 個交易日（約 3 個月）的路徑。

TGA 上升代表資金回到財政部帳戶、對市場流動性較緊；TGA 下降則代表釋出流動性。因此情境名稱依「市場流動性」而非 TGA 數字方向標示。

### 銀行準備金

以週頻率推導：

`預估準備金變動 = WALCL 趨勢 − 預估 TGA 週變動 − RRP 趨勢 + 校正殘差`

WALCL、RRP 與殘差皆採最近 13 週的中位數週變動；RRP 不得低於零。TGA 週變動由日頻 TGA 路徑週化而成。情境帶沿用 TGA 的第 25／75 百分位路徑，其他條件不變。此為流動性方向模型，不主張精準預測 Fed 準備金的會計餘額。

## 呈現

1. 摘要列：最新實際 TGA／準備金、資料日期、基準情境的 1M 與 3M 終點、相對最新值變動。
2. TGA 圖：日頻實線為已發布資料；預估為虛線；基準線外加寬鬆／緊縮區間。
3. 準備金圖：週頻實線、預估虛線與同一情境區間。
4. 圖例與說明固定揭露資料來源、更新時間、預估期間與模型公式。
5. 1M／3M 按鈕切換同一份資料，避免不同期間使用不同口徑。

## 輸出格式

`data/liquidity_forecast.json` 必須包含：

- `generated_at`、各來源的 `as_of` 日期與模型版本；
- `tga`、`reserves` 的 `actual`、`base`、`loose`、`tight` 日期和值序列；
- 1M／3M 終點摘要；
- `assumptions`，包含視窗、樣本年數與資料來源。

## 驗證

1. 單元測試驗證 TGA 路徑長度、分位數情境排序與不修改實際資料。
2. 準備金測試驗證 RRP 下限為零、週化 TGA 正確進入推導式、資料不足時不產生虛假預估。
3. 前端測試驗證 1M／3M 切換、實線／虛線、三情境、空資料容錯與摘要數字。
4. 發布前執行既有 Python 與網頁測試；正式站確認 JSON 與圖表都有新欄位。
